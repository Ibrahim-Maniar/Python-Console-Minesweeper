# Python-Minesweeper

**The classic, Minesweeper.**
##

## 🎮 How to Play
- **Step 1:** Choose a coordinate on the grid. i.e A1 (Doesn't have to be a perfect input)
- **Step 2:** A chunk of numbers will be revealed. These numbers show how many mines are in its immediate surroundings.
- **Step 3:** Use the numbers on revealed tiles to determine the position of the mines. Reveal as many tiles as you can while avoiding the mines.
- **Step 4:** Use the tile number from the new tiles and repeat until you have fully uncovered the grid. 


## 🚀 How to Run

- **Run the file Main.py**



## 🛠️ Technical Highlights

- **Defensive Programming:** Used fallback code to prevent errors and keep the program looking smooth.
- **Recursion:** Used recursion to guarantee a certain amount of mines on the grid as efficiently as possible and for a recursive flood fill.
- **2D Array Manipulation:** Used 2D arrays to track + display the coordinates and associated values. Manipulated the 2D array to form simple graphics.
- **Dictionaries:** Used dictionaries to store coordinates and their data.
- **Data Sanitisation + Parsing:** Uses data handling and formatting to convert messy inputs to data that can be read by other scripts and mitigate any errors in input.
